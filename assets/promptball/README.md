# PromptBall Assets

This folder contains implementation-ready assets extracted from the PromptBall UI mockups.

- `icons/`: SVG assets for PromptBall brand, floating ball states, Pro badge, and feature icons.
- `part1/`: detailed Part 1 floating launcher assets and manifest.
- `part2/`: detailed Part 2 workbench assets and manifest.
- `part3/`: detailed Part 3 structured prompt builder assets and manifest.
- `part4/`: detailed Part 4 prompt library and slash command assets and manifest.
- `part5/`: detailed Part 5 evaluation dashboard assets and manifest.
- `part6/`: detailed Part 6 settings assets and manifest.
- `part7/`: detailed Part 7 A/B test comparison assets and manifest.
- `tokens/`: JSON and CSS design tokens for colors, typography, spacing, radius, shadows, and motion.
- `asset-manifest.json`: machine-readable inventory and Lucide icon mapping.

Design documentation lives in `documents/designs/`.
