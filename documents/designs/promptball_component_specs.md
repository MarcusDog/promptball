# PromptBall 七部分设计稿组件规格

坐标说明：

- `ui/总设计稿.png` 坐标基准为 `1672 x 941`。
- `ui/part1.png` - `ui/part7.png` 坐标基准为 `1448 x 1086`。
- 坐标为从设计稿左上角开始估算的开发参考框，不用于视觉回归的硬性像素断言。实际实现应优先使用 token、自动布局和响应式约束。
