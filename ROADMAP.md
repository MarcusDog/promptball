# PromptBall Roadmap

## v0.1 MVP Baseline

- Floating workbench shell.
- Free, role, and voice-placeholder modes.
- DeepSeek-compatible optimization entry.
- Settings, history, templates.
- Favorite prompts, Slash command insertion, feedback, A/B, versions in prototype form.

## v0.2 Engineering Foundation

- Directory restructuring by feature.
- Type splitting and service boundaries.
- Unified error handling and logging.
- SQLite migrations.
- Encoding/documentation cleanup.
- Expanded tests and build scripts.

## v0.3 Desktop Entry

- Persistent draggable floating ball.
- Edge snapping.
- System tray.
- Startup option.
- Clipboard optimization shortcuts.
- Floating ball state indicators.

## v0.4 Prompt Editor

- Full PromptEditor.
- Structured builder with Goal, Constraints, Negative.
- Markdown editing.
- Draft autosave.
- Token estimate.
- Before/after comparison.

## v0.5 Prompt Optimizer Suite

- Optimizer, diagnosis, coach, evaluator, A/B judge, voice cleaner system prompts.
- JSON parse retry and fallback.
- Rich result page.

## v0.6 Prompt Library and Evaluation

- Complete favorite prompt schema.
- Default Slash commands.
- Version-level metrics.
- Trend and feedback views.
- Optimization reminders.
- A/B test metadata, blind evaluation, same-material comparison, and win-rate records.

## v0.7 Prompt Version Management

- Version diff.
- Rollback and set-default-version flows.
- Version-level performance metrics.
- New-version editor for prompt evolution.
- Low-score optimization reminders that can generate a new version draft.

## v0.8 Voice and Multi-Model

- Voice recording, transcript cleanup, privacy settings, and structured prompt handoff.
- Multi-provider model settings.
- Task type model routing.
- Provider logs with duration and token estimates.

## v0.9 Privacy, Import/Export, Dashboard

- Sensitive information detection. (done)
- Privacy mode and local data clearing. (done)
- Model-call warning and export redaction. (done)
- Complete built-in template library and template-to-favorite flow. (done)
- JSON/Markdown import-export.
- Analytics Dashboard.

## v1.0 Release Candidate

- Windows installer.
- App icon and release metadata.
- User data directory docs.
- Changelog and release checklist.
- Smoke-tested daily workflows.
